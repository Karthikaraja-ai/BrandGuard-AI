# BrandGuard AI — Round 2 Starter

## Included
- React + Vite frontend
- Editable prohibited terms and required phrases
- Rule-based flags for prohibited phrases, missing required phrases, possible claim language, and character limit
- Explanation and next step for each finding
- Human review queue and approval control
- Local storage persistence
- Responsive dashboard

## Run it
1. Install Node.js (LTS) from the official Node.js website.
2. Extract this ZIP.
3. Open a terminal in this folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the localhost URL printed by Vite.

To check a production build, run `npm run build`.

## Limitations to disclose
This is a rule-based prototype, not a trained AI model. It does not verify facts or automatically generate approved final copy. Local storage is for a demo only and is not a production security solution. Test it on your own machine before claiming it works or deploying it.
